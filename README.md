# JunoBlueMage PR

青魔法师 ACR，适用于国服 PromeRotation。此仓库仅分发编译后的发布包，不包含项目源码。

支持非耀星D、FATE、副本Boss和天青斗场模式，提供独立 QT、Hotkey 面板及技能装配、换技功能。

## 下载

- [下载最新发布包](https://github.com/xiaozhunuonuode/Juno-ACR-PR/releases/latest/download/JunoBlueMage.PR-0.3.1.zip)
- [查看发布版本](https://github.com/xiaozhunuonuode/Juno-ACR-PR/releases)

## 在线下载源

在 PR 的 ACR 下载源中添加下面的地址：

https://raw.githubusercontent.com/xiaozhunuonuode/Juno-ACR-PR/main/Juno.json

青魔在线下载需要 PromeRotation 1.5.10.4 或支持 BLU 下载的后续版本。

## 手动安装

下载 ZIP，将其中的 Juno 文件夹解压到 PromeRotation 的 ACR 目录，然后在 PR 中加载本地 ACR，选择作者 Juno、名称 JunoBlueMage。

适用职业：青魔法师。需要自行走位，并按实际副本设置技能装配。
